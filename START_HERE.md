## 💡 KEY FEATURES OF THIS PROJECT

### Semantic HTML5
- Proper use of `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`
- Three event articles with complete metadata
- Working skip link for keyboard users
- Proper heading hierarchy (h1 → h2 → h3)

### CSS Design System
- Custom properties (CSS variables) for colors, typography, spacing
- Typography scale: body (1rem), h3 (1.5rem), h2 (2rem), h1 (2.5rem)
- Line-heights optimized: 1.6 for body, 1.2 for headings
- Utility classes with low specificity

### Optimized Images
- SVG logo (inline, scalable)
- 3 JPEG photos (optimal compression)
- Descriptive alt text on content images
- Empty alt on decorative image
- width/height attributes (prevents layout shift)
- loading="lazy" (performance)

### Accessibility
- WCAG 2.1 Level AA compliant
- Skip navigation link
- Proper ARIA labels
- Keyboard accessible
- Screen reader friendly
- Color contrast ratios meet standards

## 🆘 NEED HELP?

### Common Issues:

**Q: Images not showing on the website?**  
A: Make sure the `assets/` folder is in the same directory as `index.html`

**Q: CSS not applying?**  
A: Verify `styles.css` is in the same directory as `index.html`

**Q: How do I validate HTML?**  
A: Run `tidy -q index.html` or use https://validator.w3.org/

**Q: How do I take screenshots?**  
A: See detailed instructions in `PDF_GENERATION_INSTRUCTIONS.md`

**Q: PDF too large?**  
A: Compress images before inserting, or use lower quality for screenshots

**Q: Can't print to PDF?**  
A: Use your browser's Print function and select "Save as PDF" as the destination
